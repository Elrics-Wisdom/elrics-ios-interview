# Elrics iOS Interview — Live Tasks

Live iOS interview tasks — Junior: User List App (Swift, API, SwiftUI) | Senior: Mini Store (MVVM, async/await, persistence + code review). Starter projects with TODOs.

## How to use (candidate)
1. Clone: `git clone https://github.com/Elrics-Wisdom/elrics-ios-interview.git`
2. Open `junior-starter/` or `mid-senior-starter/` instructions:
   - Xcode 15+ > New App > iOS SwiftUI > drag the `.swift` files in
   - Internet ON, docs allowed, no AI/chat
3. Complete TODOs in order. See folder README.

## Folders
- `junior-starter/` — 60 min: User List (Codable, URLSession, List, search)
- `mid-senior-starter/` — 90 min: Mini Store (MVVM, protocol service, Cart + UserDefaults, code review)

APIs: `https://jsonplaceholder.typicode.com/users`, `https://fakestoreapi.com/products`
